# Myor · 项目与实验

毛洋洋的个人主页，使用纯 HTML 和 CSS 构建，可直接托管在 GitHub Pages。

## 本地预览

在本目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000`。

## 发布到 GitHub Pages

1. 创建公开仓库 `myorx/myorx.github.io`。
2. 将本目录的文件推送到仓库的 `main` 分支。
3. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`、目录选 `/(root)`，保存。
4. 等待 GitHub Pages 发布后访问 `https://myorx.github.io/`。

主页只包含公开展示所需内容。申请材料、证件、成绩单、推荐信和个人联系方式没有复制到本站。
