# Yangyang Mao (Myor) · Academic Homepage

An English-language personal homepage built with plain HTML and CSS and published through GitHub Pages at [myorx.github.io](https://myorx.github.io/).

## Local preview

Run `python -m http.server 8000` in this directory, then open `http://localhost:8000/`.

## Content

The site presents public academic interests, independent experiments, software projects, and selected competition results. Private application materials, identity documents, transcripts, recommendation letters, and personal contact details are not included.
